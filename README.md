# Portfólio Pessoal

## Sobre o projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal criado para apresentar minha trajetória como estudante de **Informática para Internet**, minhas habilidades e alguns dos projetos desenvolvidos durante minha formação.

O portfólio foi desenvolvido como atividade prática da Unidade Curricular de **Versionamento e Colaboração**, com o objetivo de aplicar conhecimentos de desenvolvimento web e, principalmente, conceitos de organização e versionamento utilizando **Git e GitHub**.

O projeto foi desenvolvido de forma gradual, permitindo registrar as etapas de criação através de commits e branches.

---

## Objetivo

O principal objetivo do projeto é criar uma página pessoal simples, organizada e responsiva, capaz de apresentar:

- Informações pessoais;
- Minha formação;
- Habilidades na área de tecnologia;
- Projetos desenvolvidos;
- Forma de contato e acesso ao meu GitHub.

Além do desenvolvimento da página, o projeto busca demonstrar a utilização correta de um fluxo de versionamento durante sua construção.

---

## Tecnologias utilizadas

As principais tecnologias utilizadas no projeto são:

- **HTML5** — estrutura e organização do conteúdo da página;
- **CSS3** — estilização, layout, responsividade e identidade visual;
- **Git** — controle de versões do projeto;
- **GitHub** — armazenamento remoto e organização do repositório.
